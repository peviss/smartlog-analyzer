Tus logs, entendidos.

SmartLog Analyzer centraliza los logs de tus microservicios, los agrupa en patrones y usa un LLM para decirte qué está fallando, qué tan grave es y qué hacer.

Probalo en 2 minutos Ver el código
Miles de líneas se agrupan en unas decenas de patrones antes de llegar al modelo
Cualquier formato ECS, syslog, nginx, logfmt, OpenTelemetry, GELF, CSV…
Sin vendor lock-in Anthropic, OpenAI, Gemini, Ollama local, o un mock sin costo

Funciones

Del log crudo a la acción concreta

Ingesta en cualquier formato

Documentos ECS por API, o archivos crudos: texto plano (syslog, access logs de nginx y Apache, klog, logfmt, Python, logback), JSON (OpenTelemetry, GELF, Serilog, CloudWatch, Google Cloud, Docker) y CSV. Todo se normaliza a ECS.

Análisis con IA

Un resumen en lenguaje claro, los problemas agrupados por categoría y severidad, y acciones concretas con prioridad. La respuesta del modelo se valida contra un esquema: si no cumple, se reintenta.

Patrones antes que tokens

Antes de llamar al LLM, los mensajes se agrupan en plantillas con conteos y servicios afectados. El prompt es chico, barato y enfocado, y los números los calcula el código, no el modelo.

El estado de un vistazo

Logs, errores, tasa de error y servicios afectados del período, comparados con el anterior. Cada número lleva al detalle ya filtrado.

El modelo que prefieras

Cambiá de proveedor con una variable de entorno. Ollama corre modelos en tu máquina sin que los logs salgan de tu red, y el mock permite probar todo sin API key.

Nada se pierde

Los reintentos no duplican logs (event.id), el evento original se puede guardar tal cual llegó, y cada suposición de la normalización queda marcada con un tag visible.

Cómo funciona

Tres pasos

  1. 1

    Mandá tus logs

    Por API (POST /api/logs/batch) desde tu collector, o importando un archivo desde la UI. Los registros inválidos vuelven con su número de línea; el resto se guarda.

  2. 2

    Explorá

    Filtrá por servicio, nivel, entorno, host, traza o texto. Mirá la evolución por hora o por día y qué servicios concentran los errores.

  3. 3

    Analizá con IA

    Elegí un período o un conjunto de logs y obtené un resumen, las categorías de problemas y las acciones sugeridas, con enlaces a los logs de ejemplo.

Importación

Pegá un archivo, no un parser

Cada línea se reconoce por su formato y se traduce a ECS: niveles, timestamps en cualquier formato, servicios, hosts, trazas y stack traces. Las líneas que una app escribe dentro de syslog o de un contenedor se vuelven a parsear, así un JSON dentro de syslog conserva sus campos.

  • Errores con su número de línea, sin rechazar el archivo entero
  • Nombres de campo en cualquier estilo: traceId, trace_id, TraceId
  • Hasta 10.000 registros o 5 MB por importación

Empezar

Corre en tu máquina en 2 minutos

Solo necesitás Docker. Se levanta con datos de ejemplo y con el modelo mock, así que podés probar el análisis sin API key ni costo.

Para usar un modelo real, configurá LLM_PROVIDER y LLM_API_KEY en .env.

Guía de instalación Arquitectura 
# 1. Bajá el código
git clone https://github.com/peviss/smartlog-analyzer.git
cd smartlog-analyzer

# 2. Configurá y levantá
cp .env.example .env
docker compose up -d --build

# 3. Abrí la UI
open http://localhost:8080
